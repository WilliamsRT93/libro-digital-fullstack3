PROMPT 1 — DIAGRAMA DE INFRAESTRUCTURA (Docker Compose + Kubernetes)
==========================================================================
Pegar en el generador de diagramas con IA de draw.io (Extras > Generar diagrama).

Genera un diagrama de infraestructura de despliegue para una plataforma de
microservicios llamada "Libro de Clases Digital", en ESPAÑOL, con esta
estructura exacta:

CONTENEDOR "Entorno Docker Compose (desarrollo local)" — agrupa todo lo
siguiente en una caja punteada grande:

1. Capa de borde:
   - Caja "Frontend - Next.js 14 (puerto 3000)" — contenedor Node 22-alpine,
     conecta hacia abajo a "BFF".
   - Caja "BFF - Spring WebFlux (puerto 8080)" — conecta hacia abajo a
     "API Gateway".
   - Caja "API Gateway - Spring Cloud Gateway (puerto 8081)" — variante
     opcional en caja punteada al lado: "Kong (perfil alterno, puerto 8000
     proxy / 8001 admin)".

2. Capa de microservicios (4 cajas en fila, todas conectadas desde
   "API Gateway"):
   - "MS-Auth (puerto 8082)"
   - "MS-Academico (puerto 8083)"
   - "MS-Asistencia (puerto 8084)"
   - "MS-Mensajeria (puerto 8085)"

3. Capa de persistencia (debajo de cada microservicio, conectado 1 a 1 con
   flecha etiquetada "JPA"):
   - "postgres-auth (puerto 5432) - volumen auth_data"
   - "postgres-academico (puerto 5433) - volumen acad_data"
   - "postgres-asistencia (puerto 5434) - volumen asist_data"
   - "postgres-mensajeria (puerto 5435) - volumen msg_data"

4. Mensajeria (caja aparte, conectada con flecha punteada desde
   "MS-Asistencia" y hacia "MS-Mensajeria"):
   - "Kafka (puerto 9092)" conectado a "Zookeeper (puerto 2181)"

5. Almacenamiento de objetos (conectado con flecha punteada desde
   "MS-Academico"):
   - "MinIO / S3 (API puerto 9000, consola puerto 9001) - bucket
     reportes-academicos"

6. Observabilidad (agrupar en una caja aparte a la derecha, sin conexiones
   directas, solo agrupados):
   - "Elasticsearch (puerto 9200)"
   - "Logstash (puertos 5044 beats / 5000 TCP)"
   - "Kibana (puerto 5601)"
   - "Prometheus (puerto 9090)"
   - "Grafana (puerto 3001)"

Usa colores distintos por capa (azul para frontend, verde para BFF, amarillo
para gateway, rojo/salmon para microservicios, morado para bases de datos,
naranja para Kafka/observabilidad/almacenamiento). Incluye el puerto de cada
servicio dentro de la caja. Titulo del diagrama: "Infraestructura de
Despliegue - Libro de Clases Digital (Docker Compose)".

SEGUNDA PARTE DEL MISMO PROMPT (variante Kubernetes, opcional, como
diagrama separado o como segunda pagina del mismo archivo):

Genera un diagrama de despliegue en Kubernetes con:
- Namespace "libro-clases" conteniendo todo.
- 4 StatefulSets de PostgreSQL (uno por microservicio) con sus Secrets de
  credenciales, definidos en "postgres.yaml".
- StatefulSet de Kafka, definido en "kafka.yaml".
- 4 Deployments + Services para MS-Auth, MS-Academico, MS-Asistencia,
  MS-Mensajeria (uno por archivo: ms-auth.yaml, ms-academico.yaml,

  probes apuntando a /actuator/health.

  "api-gateway.yaml".
- Deployment conjunto de BFF + Frontend, definido en "bff-frontend.yaml".
- Estrategia de despliegue: rolling update con maxUnavailable=0 (anotarlo
  como nota en el diagrama).
Titulo: "Despliegue en Kubernetes - Libro de Clases Digital".

==========================================================================
Pegar en el generador de diagramas con IA de draw.io (Extras > Generar diagrama).

Genera un diagrama de arbol de carpetas (estilo organigrama / arbol
jerarquico, de arriba hacia abajo o de izquierda a derecha) para un
repositorio de GitHub llamado "libro-digital-fullstack3", en ESPAÑOL, con
esta jerarquia exacta (usa cajas rectangulares para carpetas y una
descripcion corta como subtitulo de cada una):

RAIZ "libro-digital-fullstack3/"
├── "README.md" - guia de instalacion y errores frecuentes
├── "docker-compose.yml" - orquestacion de desarrollo
├── "docker-compose.release.yml" - distribucion via Docker Hub

├── "bff/" - Backend For Frontend (WebFlux)
│   └── "src/main/java/.../controller/" - BffController, GlobalExceptionHandler
├── "ms-auth/" - JWT issuer + gestion de usuarios
│   └── "src/main/java/com/colegio/auth/"
│       ├── "controller/" - AuthController, UserAdminController
│       ├── "service/" - AuthService, UserAdminService
│       ├── "security/" - JwtService
│       ├── "entity/" - UserAccount, Role
│       └── "exception/" - GlobalExceptionHandler
├── "ms-academico/" - Notas + generacion de PDF + S3
│   └── "src/main/java/com/colegio/academico/"

│       └── "entity/" - Nota
├── "ms-asistencia/" - Asistencia + productor Kafka
│   └── "src/main/java/com/colegio/asistencia/"

configuracion en la raiz. Titulo del diagrama: "Estructura del Repositorio -
Libro de Clases Digital".
